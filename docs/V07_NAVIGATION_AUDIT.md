# Weeko v0.7 导航审计（Stage 0）

日期：2026-09-06  
范围：只读审计 v0.6 候选包的 `ScheduleActivity` 顶部、日期区和底部面板导航。  
阶段结论：Stage 0 完成；本文件不提出代码/UI 实施，也不启动 Stage 1。

## 成功标准与方法

成功标准是：逐一确认当前入口的可见文案、资源 ID、点击链和实际目标页面；把它们与目标结构“左 ☰ / 右 ⋮”逐项对照；明确重复入口、未知项和删除前置条件。

证据来自以下只读材料：

- `build/v0.6/Weeko-v0.6.0-test1.apk`（候选包，包名 `io.github.mxwf.weeko`）。
- `build/v0.6/device/current-ui.xml`：主课表页的可点击节点。
- `build/v0.6/device/v06-panel-safe.xml`：展开底部面板后的节点、文案与顺序。
- `build/v0.6/repro-apktool/` 中的 `ScheduleActivity.smali`、`o00000.smali` 及相关菜单/Activity smali：资源绑定、listener 和目标 Activity。

“已确认”表示 XML 与 smali/运行链一致；“推断”表示由目标结构映射得出、尚未在新 UI 验收；“待确认”表示当前证据不足，不能据此删除入口。

## 当前可见结构

主课表页从左到右包含日期/周次/星期文本区，以及四个顶部按钮：`anko_ib_add`、`anko_ib_import`、`anko_ib_share`、`anko_ib_more`。日期、周次和星期文本本身也可点击。

展开的旧底部面板第一行从左到右为：

1. `main_nav_time`：添加课程；
2. `main_nav_schedule_setting`：课表设置；
3. `main_nav_course`：全局设置；
4. `main_nav_help`：关于 Weeko。

面板同时显示周次滑块、修改当前周、新建课表、管理和课表卡片。旧的关于、反馈、设置、Suda Life 行仍在静态代码中，但当前面板已隐藏，不计入可见入口。

目标结构：左 ☰ 包含“调整周数、切换/管理课表、回到当前周”；右 ⋮ 包含“课表管理、分享、设置、关于”。底部栏计划后续移除。

| 当前入口 | 实际功能 | 目标入口 | 是否重复 | 风险 |
| --- | --- | --- | --- | --- |
| 顶部 `+` | 添加课程 | 左 ☰ → 课表管理 → 课程列表 → 添加（推断） | 是（与底部“添加课程”重复） | 高：删除前必须在目标课表管理路径实机确认新增、编辑和当前课表上下文。 |
| 底部“添加课程” | 添加课程 | 左 ☰ → 课表管理 → 课程列表 → 添加（推断） | 是（与顶部 `+` 重复） | 高：同上；当前已有管理页课程列表的备用链，但尚未作为新导航验收。 |
| 顶部 `anko_ib_import` | 展开旧底部面板 | 左 ☰（新抽屉/菜单，推断） | 是（与旧底部面板承载关系重复） | 高：底部栏移除前需先确认左侧菜单能承载面板中的周次、切换和管理能力。 |
| 日期区点击 | 修改当前周、回到当前周、新建课表混合菜单 | 左 ☰ → 调整周数；左 ☰ → 回到当前周；左 ☰ → 课表管理（新建）（推断） | 部分重复 | 高：需拆分动作并核对条件显示，避免误把“新建课表”当作周次调整。 |
| 面板“课表设置” | 课表设置（含作息/当前周等页面入口） | 左 ☰ → 调整周数；其余设置项按右 ⋮ → 设置（推断） | 部分重复 | 中：当前页面是复合设置页，拆分前需逐项列出实际字段和返回栈。 |
| 面板“管理”/课表卡片 | 课表切换与 `ScheduleManageActivity` 管理 | 左 ☰ → 切换/管理课表；右 ⋮ → 课表管理（推断） | 是（目标中两个名称需定边界） | 高：需先定义“切换”与“管理”是否同一页，避免产生两个等价入口。 |
| 顶部 `anko_ib_share` | 导出/分享菜单 | 右 ⋮ → 分享（推断） | 是（待合并） | 高：只有在右侧分享菜单覆盖备份、iCal、应用分享和在线分享后，才可删除独立按钮。 |
| 顶部 `anko_ib_more` | 教务/文件/备份/分享口令导入菜单 | 左 ☰ → 课表管理的导入子项（推断） | 待确认 | 高：目标结构未明确导入的归属；未确认前保留现入口。 |
| 面板“全局设置” | `SettingsActivity` | 右 ⋮ → 设置（推断） | 否（入口迁移） | 中：需在新右侧菜单确认入口可达并保留返回栈。 |
| 面板“关于 Weeko” | `AboutActivity` | 右 ⋮ → 关于（推断） | 否（入口迁移） | 低：目标页面与当前页面一致，但仍需新菜单实机确认。 |

## 删除与迁移闸门

1. **底部栏**：只能在左 ☰ 与右 ⋮ 的等价能力完成实机验收后移除；本审计没有授权删除。
2. **独立分享按钮**：只有右 ⋮ → 分享已覆盖当前四类分享/导出分支，并验证返回栈后，才可删除顶部独立分享按钮。
3. **重复添加入口**：顶部 `+` 与底部“添加课程”都已确认进入同一 `AddCourseActivity`；但课程管理页的“课程列表 → 添加”虽已由 smali 确认存在，仍需在目标导航中实机验证可发现、可用，再删除其中一个或两个独立入口。
4. **导入入口**：`anko_ib_import` 的实际行为是展开旧面板，`anko_ib_more` 才是导入菜单。两者不能按资源 ID 或图标名称互换，目标菜单归属待 Stage 1 决定。

## Stage 0 结论

当前导航存在三类需要在下一阶段处理的语义错位：顶部按钮资源名与实际行为不完全一致；日期区一个点击区承载多个不同目的；底部面板既承载快捷入口又承载课表选择/管理。目标左/右菜单可以覆盖这些能力，但“课表管理”与“切换/管理课表”的边界、导入归属，以及添加课程的最终唯一入口仍未完成可发现性验收。

本轮仅新增本审计文档，未修改代码、资源、APK、业务逻辑或 UI；不应据此开始 Stage 1 以外的实现工作。
