# Weeko v1.0.1 发布报告

状态：已完成本地发布包构建与设备回归  
日期：2026-09-11（Asia/Shanghai）

## 修复内容

- 后台清理后不再重复显示新手引导：引导完成回调将 `has_intro` 写入从异步
  `SharedPreferences.Editor.apply()` 改为同步 `commit()`，确保进程被回收前已经落盘。
- 导入引导链与当前菜单保持一致：导入课表提示直接衔接到现有“更多操作”入口，
  不再跳转到已经移除的分享按钮。
- 版本元数据升级为 `versionCode=13`、`versionName=1.0.1`；数据库、Preference
  key、备份格式、Widget 和旧 Activity/Provider/Receiver 名称均未改写。
